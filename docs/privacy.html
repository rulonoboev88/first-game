First Game — Privacy Policy

Last updated: November 9, 2026

English

First Game is a free game for babies and toddlers (ages 5 and under). It does not collect, store on any server, or share any personal or non-personal data.

  • No accounts and no sign-in.
  • No advertising and no in-app purchases.
  • No analytics, no tracking, no advertising ID, and no third-party SDKs.
  • The app has no internet permission and cannot send anything anywhere by itself. The only permission it asks for is vibration (gentle feedback on touch).
  • Parent settings (which games are shown, play-time limit, language and so on) are stored only on the device.
  • If something goes wrong inside a game, a short technical error note (app version, game name and the error text — no personal data) is kept only on the device. It leaves the device only if a parent opens “For parents → Error report” and chooses to send it with the phone’s standard Share menu (e-mail, messenger). The parent sees and chooses where it goes.
  • Nothing the child does in the game leaves the device.

The source code is open: github.com/rulonoboev88/first-game.

Questions: please open an issue in the repository above.

Українська

First Game — безкоштовна гра для малят (до 5 років). Застосунок не збирає, не зберігає на жодних серверах і нікому не передає жодних даних.

  • Без облікових записів і входу.
  • Без реклами та покупок.
  • Без аналітики, відстеження, рекламного ідентифікатора та сторонніх SDK.
  • Застосунок не має дозволу на інтернет і сам нічого нікуди надіслати не може. Єдиний дозвіл — легка вібрація при дотику.
  • Налаштування для батьків (які ігри видно, час гри, мова тощо) зберігаються лише на пристрої.
  • Якщо в грі стається збій, коротка технічна примітка (версія, назва гри, текст помилки — без особистих даних) зберігається лише на пристрої. Вона залишає пристрій тільки тоді, коли батьки самі відкривають «Для батьків → Звіт про помилки» і надсилають її через стандартне меню «Поділитися» (пошта, месенджер).
  • Ніщо з того, що дитина робить у грі, не залишає пристрій.

Відкритий вихідний код: github.com/rulonoboev88/first-game.
