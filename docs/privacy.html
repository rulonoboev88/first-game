First Game — Privacy Policy

Last updated: November 5, 2026

English

First Game is a free game for young children. It does not collect, store, or share any personal or non-personal data.

  • No accounts, no sign-in.
  • No advertising and no in-app purchases.
  • No analytics, tracking, or third-party SDKs.
  • The app does not request internet access and cannot send anything anywhere. It only requests permission to vibrate (for gentle touch feedback).
  • Nothing the child does in the game leaves the device.

The source code is open: github.com/rulonoboev88/first-game.

Questions: please open an issue in the repository above.

Українська

First Game — безкоштовна гра для малят. Застосунок не збирає, не зберігає і нікому не передає жодних даних.

  • Без облікових записів і входу.
  • Без реклами та покупок.
  • Без аналітики, відстеження та сторонніх SDK.
  • Застосунок не має доступу до інтернету й фізично не може нічого надіслати. Єдиний дозвіл — легка вібрація при дотику.
